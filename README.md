📇 Digital Business Card – Responsive Web Project

A modern, fully responsive Digital Business Card Website built using HTML, CSS, Bootstrap, and Font Awesome.
This project includes multiple pages, an admin dashboard, analytics page, profile editor, and an interactive digital business card.

🚀 Features
⭐ Main Website

Clean and modern homepage design

Hero section with dynamic image

Quick card preview section

Navigation links to Gallery, Testimonials, Pricing, and FAQ

⭐ Admin Module

Admin Dashboard

Profile Editor

Analytics Page (graphs, metrics, charts)

Secure access (planned with authentication)

⭐ Digital Business Card

Fully responsive card layout

Ready to share

Compact and professional design
